# Figures

No figure files are included in this public release.

The project's publication figures are currently withheld pending laboratory
authorization. When authorization is received, the following figure sets will be
added with English captions and validation-split scope statements:

- validation benchmark comparison for `TaxoFunc-P2FM-ens-v2`;
- flow-matching trajectory for `TaxoFunc-P2FM-ens-v2`;
- forward/reverse latent-density diagnostics;
- endpoint joint-density diagnostic.

All are validation-split results for `TaxoFunc-P2FM-ens-v2`. No other model
version, held-out evaluation, or external-cohort result will be mixed in.

The figure source files are not part of this repository, and the release does not
claim that the figures can be regenerated from the included code alone.
